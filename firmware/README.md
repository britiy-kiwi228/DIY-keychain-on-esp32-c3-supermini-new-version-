# WIRED KEYCHAIN // ESP32-C3 SUPERMINI FIRMWARE

Прошивка для DIY цифрового брелока на базе **ESP32-C3 SuperMini** и 1.3"/1.28" IPS дисплея ST7789 (240×240).

---

## 1. Аппаратная распиновка (Fixed Pinout)

| Функция | Пин ESP32-C3 | Примечание |
|---|---|---|
| **TFT_SCLK** | `GPIO 4` | SPI Clock |
| **TFT_MOSI** | `GPIO 6` | SPI Data / SDA |
| **TFT_CS** | `GPIO 7` | Chip Select |
| **TFT_DC** | `GPIO 5` | Data / Command |
| **TFT_RST** | `GPIO 3` | Hardware Reset |
| **TFT_BLK** | `GPIO 2` | Подсветка экрана (LEDC PWM) |
| **PIN_BUTTON** | `GPIO 10` | Тактовая кнопка на GND (`INPUT_PULLUP`) |
| **PIN_BAT_ADC** | `GPIO 0` | Делитель напряжения батареи: 100k / 100k |
| **PIN_VBUS_SENSE** | `GPIO 1` | Делитель напряжения USB 5V: 100k / 100k |

---

## 2. Логика работы устройства (Finite State Machine)

1. **Режим воспроизведения (`STATE_PLAYBACK`)**:
   - Частота процессора: **80 МГц** (экономия батареи).
   - Wi-Fi модуль полностью обесточен (`WiFi.mode(WIFI_OFF)`).
   - Подсветка дисплея: 40% (ШИМ 5 кГц).
   - GIF декодируется **построчно** прямо из LittleFS в окно дисплея ST7789 (расход RAM всего ~480 байт!).
   - **Короткий клик кнопки (< 0.5 с)**: переключение слота анимации (Слот 1 → 2 → 3 → 1).
   - **Удержание кнопки (2.5 – 5.0 с)**: переход в режим Captive Portal.
   - **Длинное удержание (> 5.0 с)**: переход в режим глубокого сна (`Deep Sleep`). Пробуждение по нажатию на кнопку (GPIO 10).

2. **Режим портала (`STATE_PORTAL`)**:
   - Частота процессора: **160 МГц**.
   - Точка доступа: `WIRED_KEYCHAIN` (пароль: `love_keychain`).
   - DNS Captive Portal: все запросы перенаправляются на `192.168.4.1`.
   - **Два QR-кода на круглом экране**:
     - **QR #1**: Мгновенное подключение к Wi-Fi для смартфона.
     - **QR #2**: Прямая ссылка на веб-интерфейс `http://192.168.4.1`.
     - Короткий клик кнопки переключает между QR #1 и QR #2.
   - Удержание кнопки (2.5 с): выключение Wi-Fi и возврат к воспроизведению.
   - Авто-таймаут: если за 5 минут никто не подключился, брелок сам возвращается в режим воспроизведения.

3. **Режим зарядки (`STATE_CHARGING_SLEEP`)**:
   - При подключении кабеля USB Type-C экран отправляется в сон (`SLPIN`), подсветка отключается.
   - Защищает аккумулятор от паразитной нагрузки во время зарядки TP4056.

## 3. Сборка и прошивка через PlatformIO (VS Code)

1. Откройте папку `/firmware` в **VS Code** с установленным расширением **PlatformIO IDE**.
2. Подключите ESP32-C3 SuperMini через USB-кабель.
3. Нажмите кнопку **PlatformIO: Upload** (стрелочка внизу).
4. Загрузка веб-интерфейса в файловую систему LittleFS:
   - Положите файл `index.html` в папку `firmware/data/index.html`.
   - Выполните задачу: `PlatformIO -> Project Tasks -> Upload Filesystem Image`.

---

## 4. Сборка через Arduino IDE

1. Установите библиотеки через Library Manager:
   - `TFT_eSPI` by Bodmer
   - `AnimatedGIF` by Larry Bank
   - `QRCode` by Richard Moore
2. В файле `TFT_eSPI/User_Setup.h` настройте драйвер ST7789 240x240 и пины (4, 6, 7, 5, 3, 2).
3. Плата: **ESP32C3 Dev Module**.
4. Схема разделов: **Huge APP (3MB No OTA / 1MB SPIFFS/LittleFS)** или **Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**.
5. Нажмите **Загрузить**.
